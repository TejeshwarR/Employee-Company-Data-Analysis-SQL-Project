# Employee & Company Data Analysis – SQL Project

---

## 📌 Project Overview

This project focuses on **Employee and Company Data Analysis using SQL**, applying **EDA and data cleaning techniques directly within SQL** to analyze organizational structure, workforce distribution, and compensation trends.

The analysis simulates a **real-world HR / people analytics use case**, where multiple relational tables are joined and queried to generate insights for workforce planning and management.

---

## 🎯 Goals of the Project

* Perform **SQL-based EDA** on employee and company datasets
* Clean and standardize employee, role, and salary data
* Analyze workforce distribution across companies and functions
* Study salary patterns by role, company, and function
* Demonstrate analytical SQL skills using joins and aggregations

---

## 🗂️ Project Files

* **employees data analysis.sql** – SQL queries used for analysis
* **companies.csv** – Company-level master data
* **employees.csv** – Employee demographic and employment data
* **functions.csv** – Job functions / roles
* **salaries.csv** – Salary and compensation details

---

## 🧾 Dataset Overview

The project uses multiple related datasets:

* **Companies** – Company identifiers and attributes
* **Employees** – Employee details such as ID, company, function
* **Functions** – Job roles and functional classifications
* **Salaries** – Compensation details linked to employees

Together, these tables represent a **normalized relational HR database**, commonly seen in enterprise systems.

---

## 🧹 Data Cleaning & EDA Skills (SQL-Based)

The project applies **EDA and data cleaning concepts using SQL**, including:

* Handling missing or null salary values
* Standardizing function and company identifiers
* Filtering invalid or incomplete employee records
* Exploring distributions using `COUNT`, `AVG`, `MIN`, `MAX`
* Identifying salary outliers and inconsistencies

These steps ensure the data is **analysis-ready** before generating insights.

---

## 🧭 Analysis Steps / Methodology

1. **Schema Understanding**
   Reviewed table structures and relationships.

2. **Data Cleaning (SQL)**
   Cleaned employee, function, and salary data using SQL logic.

3. **Exploratory Data Analysis (EDA)**
   Explored employee counts, role distribution, and salary ranges.

4. **Relational Analysis**
   Used joins to combine company, employee, function, and salary data.

5. **Insight Interpretation**
   Translated query results into workforce insights.
